    Suavizado de control (rampa, no PID)

    Sin encoder no hay error real que corregir en lazo cerrado — esto solo limita cuánto puede cambiar v/ω por segundo entre un comando y el siguiente, para evitar tirones.

    Aceleración lineal máx.1.0 m/s²
    Aceleración angular máx.3.0 rad/s²

    Velocidad máxima del robot

    Techo al que corresponde el 100 % del acelerador. Deben coincidir con V_MAX / VY_MAX / OMEGA_MAX del firmware: si acá pedís más, el ESP32-C3 lo recorta en silencio y el dashboard muestra una velocidad que el robot nunca alcanza.

    Velocidad lineal máx.0.55 m/s
    Velocidad angular máx.1.5 rad/s

    Frenado por LIDAR

    Mide dentro de un corredor del ancho del robot (no un cono), así en pasillos estrechos no frena por las hileras de los lados. Corta los motores con antelación suficiente para el deslizamiento: el robot no tiene gama lenta real ni freno. Largo y ancho deben coincidir con el footprint de nav2_params.yaml.
