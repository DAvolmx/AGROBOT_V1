Van por la API de ChirpStack a la cola del dispositivo. El nodo es clase A: solo escucha en dos ventanas cortas justo después de cada envío, así que un comando tarda hasta 30 s en llegar. No es un mando en tiempo real. Para frenar en el acto está el enlace directo con el ESP32-C3.
